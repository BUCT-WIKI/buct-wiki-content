# 辅修专业与微专业指南

> 快速了解辅修学士学位和微专业的区别、申请条件及最终收获，助您选择适合自己的跨专业学习路径。

## 一、概述

学校面向本科生开设两类跨专业修读项目：**辅修学士学位**和**微专业**。前者周期长、学分多，完成后可在主修学位证书中注明辅修学位；后者周期短、灵活度高，完成后颁发微专业学习证书（不授学位）。两者均按学分收费（150元/学分），但招生对象、修读要求差异明显。本指南基于学校最新管理办法提炼核心信息，供参考决策。

> **注意**：每名学生只能选择修读其中一个项目，请结合自身学业负担和职业规划慎重选择。

## 二、辅修学士学位（核心信息）

- **招生对象**：全日制普通本科**一年级**学生（不含双学位、第二学士学位及联合培养）。
- **招生时间**：每学年**第二学期**，通过教务管理系统报名。
- **学分与年限**：总学分 **45~50** 分，修读约 **3年**。
- **开课形式**：录取≥40人单独编班（晚上/周末上课），不足40人随主班修读。
- **申请门槛**：主修专业累计GPA ≥ 2.5，无纪律处分，且满足开设院系其他要求。
- **授予凭证**：完成全部学分且主修获得学位→授予辅修学士学位（在主修学位证书中注明），同时发放辅修专业证书；若主修仅毕业未获学位，则只发辅修专业证书，待主修补授学位后可补授辅修学位。
- **退出机制**：主修GPA低于2.0时将被终止资格；终止后已修学分可转为素质教育或选修课学分。

## 三、微专业（核心信息）

- **招生对象**：全日制普通本科**二、三年级**学生。
- **招生时间**：每学年**第一学期**，通过教务管理系统报名。
- **学分与年限**：总学分 **10~15** 分，修读约 **1.5学年**。
- **开课形式**：单独开班（晚上/周末），**申请人数≥30人**方可开课。
- **申请门槛**：学有余力，且满足开设院系具体要求。
- **授予凭证**：修完所有课程并取得学分→发放**微专业学习证书**，**不授予学位**。
- **特别规定**：不允许免修或自修，无缓考和补考，成绩单单独制发；终止后可转已修学分为素质教育课程学分。

## 四、关键对比一览

| 维度 | 辅修学士学位 | 微专业 |
| --- | --- | --- |
| 招生年级 | 大一 | 大二、大三 |
| 招生学期 | 第二学期 | 第一学期 |
| 总学分 | 45~50 | 10~15 |
| 修读年限 | 约3年 | 约1.5年 |
| 开课门槛 | 录取≥40人编班 | 申请≥30人开课 |
| 可免修/自修 | 可申请 | 不允许 |
| 补考/缓考 | 按学校规定 | 无补考、无缓考 |
| 最终凭证 | 辅修学士学位（证书注明）+辅修专业证书 | 微专业学习证书 |
| 学费标准 | 150元/学分 | 150元/学分 |

## 五、费用与注册

两个项目均按 **150元/学分** 收费，每学期需按时注册缴费。开课后两周内退课可退费？——规定中明确“开课两周后申请退课，已缴学费不予退回”，请确认后再选课。

> **提示**：注册逾期将被视为自动放弃修读资格。
