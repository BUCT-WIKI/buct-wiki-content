# 课程考核与成绩制度

本节解释平时成绩与期末成绩的⽐例、绩点（GPA）计算⽅法、缓考/补考/重修政策，以及成绩查询与成绩单打印方式。
## 1. 概述

>本节旨在介绍北京化工大学本科生课程考核与成绩评定的核心规范。考核是检验教学效果、评定学业水平的重要环节，其成绩直接关联学籍管理、评奖评优及毕业资格。内容涵盖考核方式、成绩构成、补考重修、缓考申请及违纪处理等关键制度。适用于全体在校本科生，是规划学业进程、维护学术诚信的必备指南。

## 2. 课程考核与成绩制度详解

### 2.1 成绩以及绩点计算

### 2.1.1 总评成绩计算
总评成绩是学生修读课程后所获得的该门课程的最终成绩。总评成绩一般应由**过程性考核成绩（平时分）**和 **结果性考核（期末考试分）** 成绩综合得出。过程性考核成绩一般是指教学过程中的平时作业、阶段测验、期中考试、上机测试等考核性环节的成绩。结果性考核成绩一般指课程的期末考核成绩。结果性考核成绩在总评成绩中的占比不得高于70%（不同科目的过程性考核成绩和结果性考核成绩的占比不同，具体情况参见该科目的教学大纲，可以在北化在线平台查看）。
#### 2.1.2 平均学分绩点（GPA）计算
学校采用平均学分绩点（GPA）来衡量学生的学习质量。平均学分绩点（GPA）的计算方法为：
(精确到小数点后两位)

1.学分绩点的计算方法：一门课的学分绩点=绩点×学分数。
2.平均学分绩点的计算方法：平均学分绩点=所学课程学分绩点之和÷所学课程学分之和。

课程成绩的平均学分绩点（GPA）统计有三种形式：课程全部成绩的平均学分绩点（GPA）、课程最高成绩的平均学分绩点（GPA）和课程正考成绩的平均学分绩点（GPA）。由于课程性质的不同，其课程成绩的记载方式分别为百分制、字母制和两级分制，因此有必要换算成统一的成绩，也就是“课程绩点”。 课程的总评成绩与课程绩点的对应关系见下表。

| 百分制       | 字母制  | 两级分制 | 对应绩点 |
| --------- | ---- | ---- | ---- |
| 95≤成绩≤100 | A+   | /    | 4.33 |
| 90≤成绩<95  | A    | /    | 4.00 |
| 85≤成绩<90  | A-   | /    | 3.67 |
| 82≤成绩<85  | B+   | /    | 3.33 |
| 78≤成绩<82  | B    | /    | 3.00 |
| 75≤成绩<78  | B-   | /    | 2.67 |
| 72≤成绩<75  | C+   | /    | 2.33 |
| 68≤成绩<72  | C    | /    | 2.00 |
| 64≤成绩<68  | C-   | /    | 1.67 |
| 61≤成绩<64  | D+   | /    | 1.33 |
| 成绩=60     | D    | /    | 1.00 |
| 成绩<60     | F    | /    | 0.00 |
| /         | P    | /    | /    |
| 成绩≥60     | Pass | 合格   | /    |
| 成绩<60     | U    | 不合格  | /    |
| 成绩“空白”    | /    | /    | /    |
素质教育课程、采用两级制计分的课程，以及**体育课程**不参与平均学分绩点（GPA）的计算，其他课程都要计入平均学分绩点（GPA）。
### 2.2 缓考/补考/重修政策
#### 2.2.1 缓考政策
因患病或其他特殊情况不能参加课程考核的学生，可申请缓考。缓考应在该课程考核前提出申请；考试当日突患疾病或遇突发事故的，一般应在次日提出申请。学生须登录教务管理系统，选择【报名申请】-【缓考、免体、补选报名】进行申请操作。具体流程可询问院系教务老师或者参见教务管理系统【文件】栏目第一个“办理缓考的操作流程”
因病申请缓考的学生，申请材料须包含校医院或学校指定医院的诊断证明或急诊证明，经院（系）审核后，由教务处审批。因事申请缓考的学生，申请材料须包含情况说明、准假证明，由学院辅导员签字确认后，经院（系）审核后，由教务处审批。本人确因特殊情况不能办理的，可由他人持有关证明代为办理。
缓考课程不再单独安排课程考试。必修课程的缓考随补考进行；缓考选修课程的学生，可以在后续学期重修该门课程或者选修其他课程。
#### 2.2.2 补考和重修政策
必修课程正考不及格须参加下学期初补考；补考仍不及格或未参加补考者，必须重修；实践环节（军训、实习、毕设等）无补考，直接重修 。**如果学生期末考试缺考，则不能补考，直接重修。**
‌重修方式‌：
‌（1）跟班重修‌：须全程参与教学（考勤、作业、期中、期末），总评=平时+期末；受教室容量和时间冲突限制 。
‌（2）自修重修‌（跟班自修）：仅参加期末考试，无平时成绩，总评=卷面分；适用于上课时间冲突或非禁修课程；‌政治理论、体育、实验、通识课及必修实践环节不得自修‌ 。
‌（3）单开班重修‌：针对不及格人数多的基础课单独开班，仅限未通过者，必须全程上课，不可自修 。
‌成绩记载‌：
重修成绩标记“重修”；同一课程多次重修取‌最高成绩‌记载（课程代码一致时自动识别）；重修‌不可办理缓考‌ 。
‌选课流程‌：
所有重修须先选课再上课；路径为教务系统"‌报名申请→重修报名‌"；错过选课时间通常无法补选，需联系学院教务 。
限制与注意事项:
‌禁止自修范围‌：政治理论课、德育课、体育课、实验课、通识教育课、必修实践环节（军训、实习、课程设计、毕设）必须跟班全程修读 。‌专业选修课原则上不建议重修，部分通知明确“专业选修课不能重修”或需手工申请且受名额限制 。
‌课程代码一致性‌：若重修课程与原修课程代码不一致，可能需大四上学期申请课程替代，否则不计入毕业学分 。
‌作弊处理‌：考试违纪/作弊者成绩记 0 分/F，取消补考资格，只能重修 。‌‌

### 2.3 成绩查询与成绩单打印方式

学生成绩查询可以在教务管理系统（[jwglxt.buct.edu.cn](https://experimental-auth-endpoint.buct.edu.cn/?timestamp=1786009011611&service=https%3A%2F%2Fjwglxt.buct.edu.cn%2Fsso%2Fjziotlogin)）直接查询，也可在图书馆一楼利用机器查询。专业排名查询则只能在图书馆一楼的机器查询，成绩单和成绩证明打印也是在图书馆1楼的机器进行打印。
