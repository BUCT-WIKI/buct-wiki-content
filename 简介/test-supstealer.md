# Part1
校园维基，通常指由在校学生或校友自发创建、维护的知识库型社区。这类站点以[[维基]]（Wiki）技术为基础，围绕某一高校的学习、生活、办事流程与经验信息进行持续整理与共享，强调协作编辑、公开访问与经验传承。

与学校官方信息平台不同，校园维基往往更贴近学生真实需求，内容更具实践性和“过来人视角”，在一定程度上弥补了官方渠道在细节、时效性和可读性方面的不足。

== 发起背景与动机 ==

校园维基的产生，通常源于以下几类现实需求：

* 信息分散且更新滞后：课程安排、选课经验、行政流程、校园设施等信息分散在多个渠道，且官方说明往往简略。
* 经验难以沉淀：学长学姐的学习路线、踩坑经验、竞赛与保研/出国心得，随着毕业而流失。
* 学生自治文化：部分高校拥有较强的技术社群或开源文化，学生希望以更开放的方式共建知识体系。

# Part2
在这些背景下，一些学生选择以 Wiki 的形式，将零散信息结构化、长期保存，并交由社区共同维护。

== 内容范围与常见主题 ==

不同校园维基的侧重点有所不同，但常见内容包括：

* 学习与教学
** 课程介绍与评价
** 教材与参考资料
** 专业学习路线与经验分享

* 教务与行政
** 选课、转专业、考试、毕业流程
** 奖学金、评优评奖说明

* 校园生活
** 食堂、宿舍、校园设施
** 校园交通、周边生活指南

* 发展与规划
** [[保研]]、考研、出国、就业经验
** 竞赛、科研、项目实践

* 文化与社群
** 学校传统、社团介绍
** 技术社群与学生组织记录

这些内容通常以条目形式呈现，强调可持续更新，而非一次性整理。

== 社区形态与组织方式 ==

校园维基大多具备以下特点：

* 非官方性质：由学生个人或小团队发起，与学校行政体系无直接隶属关系。
* 协作编辑：任何符合规则的用户均可参与编辑，依靠社区共识维护内容质量。
* 长期运营：优秀的校园维基往往会通过招募维护者、文档规范、自动化工具等方式，降低代际交接成本。

部分站点还会配套使用 [[Git]]、论坛、即时通讯群组等工具，辅助协作与治理。

== 多维基并存现象 ==

值得一提的是，由于校园维基多为学生自发创建，同一学校内可能同时存在多个校园维基，并按主题或适用人群自然分化，例如：

* 面向新生的校园生活指南
* 面向高年级学生的学习或升学经验手册
* 面向特定学院、专业或技术方向的知识库

这种并存状态并非重复建设，而是反映了不同群体对信息深度、语气与侧重点的差异化需求。

（例如福州大学校园指南与福州大学飞跃手册是两个社区）

== 影响与意义 ==

校园维基在实践中产生了多方面的积极影响：

* 降低新生与转专业学生的信息获取成本
* 促进经验共享，减少“重复踩坑”
* 培养学生的文档意识、协作能力与公共精神
* 在一定程度上形成学校的“民间知识记忆”
